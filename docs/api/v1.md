# ODP API v1

## Purpose

API v1 establishes the technical API boundary for the ODP backend.

This version provides infrastructure for communication between the backend and future client applications.

Business workflows are intentionally excluded at this stage.

---

## Base Path

All API v1 endpoints use:

`/api/v1`

---

## Response Standard

All API responses should follow a consistent JSON structure.

### Success

```json
{
    "status": "success",
    "message": "API is healthy.",
    "data": {
        "service": "api",
        "version": "v1"
    }
}

{
    "status": "error",
    "message": "Resource not found.",
    "data": null
}
